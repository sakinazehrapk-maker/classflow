# ClassFlow
> A web application that helps students organize their academic life with a timetable, a live widget to track classes, attendance tracker, assignment manager, and exam countdown, all in one place.

---

## Features

* Create and manage your weekly class schedule
* Color-code subjects
* View classes in a timetable layout
* Delete classes anytime

<img width="1354" height="594" alt="image" src="https://github.com/user-attachments/assets/bd20e44b-afae-4051-b90e-14b5fcc476e4" />
