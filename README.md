# ClassFlow
> A web application that helps students organize their academic life with a timetable, a live widget to track classes, attendance tracker, assignment manager, and exam countdown, all in one place.

---

## Features

### Weekly Timetable

* Create and manage your weekly class schedule
* Color-code subjects
* View classes in a timetable layout
* Delete classes anytime

### Live Class Widget

A floating widget that displays:

* Current class
* Classroom
* Time remaining
* Progress bar
* Next upcoming class
* Live clock

### Today's Schedule

* Automatically displays today's classes
* Highlights the currently active class

### Attendance Tracker

* Track attendance for every subject
* Mark classes as Present or Absent
* Automatic attendance percentage calculation

### Assignment Manager

* Add assignments by subject
* Set due dates
* Assign priority levels
* Mark assignments as completed
* Data saved locally

### Exam Countdown

* Add upcoming exams
* Countdown in days until each exam

### Dark Mode

* One-click light/dark mode toggle
